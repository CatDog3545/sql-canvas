# SQL Canvas — Визуальный конструктор SQL-запросов

Интерактивное веб-приложение для визуального построения SQL-запросов на бесконечном полотне. Создавайте сложные запросы, перетаскивая блоки и соединяя их линиями — SQL генерируется автоматически в реальном времени.

## 🎯 Возможности

### Бесконечное полотно
- **Панорамирование**: зажмите и тяните пустое место
- **Масштабирование**: колесо мыши или кнопки ± в панели инструментов
- **Сброс вида**: кнопка "Сброс" возвращает к начальному положению
- **Точечная сетка**: помогает ориентироваться на полотне

### 9 типов блоков

| Блок | Назначение | Пример |
|------|-----------|--------|
| **TABLE** | Источник данных (FROM) | `users` |
| **SELECT** | Выбор колонок | `id, name, email` |
| **WHERE** | Фильтрация строк | `age >= 18 AND active = true` |
| **JOIN** | Объединение таблиц (INNER/LEFT/RIGHT/FULL) | `ON users.id = orders.user_id` |
| **GROUP BY** | Группировка | `category, status` |
| **HAVING** | Фильтр после группировки | `COUNT(*) > 5` |
| **ORDER BY** | Сортировка (ASC/DESC) | `created_at DESC` |
| **LIMIT** | Ограничение количества строк | `100` |
| **SUBQUERY** | Вложенный запрос с псевдонимом | `AS sq` |

### Создание соединений

1. **Начало**: зажмите правый порт (●) блока-источника
2. **Тяните**: появится пунктирная линия
3. **Завершение**: отпустите на левом порту целевого блока
4. **Удаление**: кликните по линии соединения

**Особенности JOIN**:
- Два входных порта:
  - **Верхний левый** — основная таблица
  - **Нижний левый** — присоединяемая таблица (помечен "JOIN")

### Контекстное меню

- **ПКМ на пустом месте** → выберите тип блока для добавления
- Блок появится в позиции курсора

### Управление блоками

- **Перемещение**: тяните за заголовок блока
- **Выделение**: клик по блоку (подсветка синей рамкой)
- **Удаление**: 
  - Кнопка ✕ в заголовке
  - Клавиша `Delete` или `Backspace` (для выделенного блока)
- **Редактирование**: заполняйте поля прямо в блоке

### SQL Preview

- **Автоматическая генерация**: SQL обновляется в реальном времени
- **Несколько цепочек**: поддерживаются независимые запросы одновременно
- **Подсветка синтаксиса**: ключевые слова выделены цветом
- **Копирование**: кнопка "Копировать" для каждого запроса
- **Сворачивание**: панель можно скрыть/показать

## 💡 Примеры использования

### Простой запрос

```
TABLE(users) → SELECT(id, name, email) → WHERE(age >= 18) → ORDER BY(name ASC) → LIMIT(25)
```

**Результат**:
```sql
SELECT id, name, email
FROM users
WHERE age >= 18
ORDER BY name ASC
LIMIT 25
```

### JOIN с группировкой

```
TABLE(orders) → JOIN(INNER) ← TABLE(users)
     ↓
GROUP BY(user_id) → HAVING(COUNT(*) > 5) → SELECT(user_id, COUNT(*) as total)
```

**Результат**:
```sql
SELECT user_id, COUNT(*) as total
FROM orders
INNER JOIN users ON orders.user_id = users.id
GROUP BY user_id
HAVING COUNT(*) > 5
```

### Подзапрос

```
TABLE(products) → WHERE(price > 100) → SUBQUERY(expensive)
                                                    ↓
TABLE(orders) → JOIN(LEFT) ← [expensive] → SELECT(*)
```

**Результат**:
```sql
SELECT *
FROM orders
LEFT JOIN (SELECT * FROM products WHERE price > 100) AS expensive
ON orders.product_id = expensive.id
```

## 📐 Архитектура

### Генерация SQL

Алгоритм рекурсивно обходит граф от терминальных узлов (без исходящих соединений) к источникам:

1. Находит все терминальные узлы
2. Для каждого строит структуру запроса (`QueryParts`)
3. Рекурсивно собирает FROM, JOIN, WHERE, GROUP BY и т.д.
4. Форматирует в SQL-строку

### Координатная система

- **Canvas-координаты**: абсолютные позиции узлов на полотне
- **Screen-координаты**: позиции на экране
- **Преобразование**: `canvasX = (screenX - viewport.x) / viewport.zoom`

### Состояние

- `nodes: SqlNode[]` — массив блоков
- `edges: Edge[]` — массив соединений
- `viewport: { x, y, zoom }` — позиция и масштаб полотна
- `selectedNodeId` — выделенный блок
- `linking` — состояние протягивания соединения
